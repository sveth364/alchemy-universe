# Алхимия Вселенной — Telegram Mini App

Игра-алхимия: соединяешь два элемента — получаешь новый, цель — «Вселенная».
Чистый HTML/JS без сборки и зависимостей. Хостинг — GitHub Pages из корня ветки `main`
(обновление доходит до игроков за ~10 минут). Игру открывает бот **@alchemia_universumbot**.

Владелец пишет по-русски и тестирует на телефоне прямо в Telegram. Отвечай по-русски,
сообщения коммитов — тоже по-русски.

## Файлы
- `index.html` — вся игра: разметка, стили, логика (поле, drag-and-drop на Pointer Events,
  список, подсказки, справка «?», режимы, статистика, «На поле», награды, темы).
- `elements.js` — `ERAS` (9 эпох), `ELEMENTS` `[id, имя, эмодзи, эпоха]`, `RECIPES` (`'a+b=результат'`), `GOAL`.
- `modes.js` — режимы: `classic` (огонь/вода/земля/воздух) и `cosmos` (энергия/пространство/время/кварк).
  У режима есть `extra` (свои рецепты, перекрывают общие) и `exclude`. `buildMode(id)` собирает набор.
- `info.js` — тексты справки: `INFO` (все элементы) и `INFO_CLASSIC` (отличия для «Классики»).
- `icons.js` + `icons-<эпоха>.js` — SVG-иконки элементов; `icons-ui.js` — иконки интерфейса,
  `ERA_ICON`, иконка эпохи «Человек» (`era_human`). `icons.html` — витрина всех иконок.
- `sound.js` — звуки, синтез через Web Audio (без файлов), объект `Sound`.
- `validate.js` — проверка данных: `node validate.js` (должно закончиться `OK`).

## Обязательные правила
1. **После любой правки `.js` поднимай метку версии** у всех `<script src="...js?v=N">` в `index.html`
   (одно и то же N+1 у всех). Иначе Telegram отдаёт игрокам старые файлы из кэша.
2. **После правки рецептов/элементов/режимов** запускай `node validate.js` и смотри глубину цели:
   сейчас «Классика» — 14 шагов, «Космос» — 31. Заметный рост — повод поискать замену рецепту.
3. **`ELEMENTS` — только добавлять в конец.** Найденные рецепты в сохранении кодируются номером
   элемента в этом массиве; перестановка сломает сохранения игроков.
4. Сохранение: localStorage `alchemy_universe_v3` + Telegram CloudStorage (лимит 4 КБ на ключ,
   поэтому ключи по режимам: `au3_meta`, `au3_classic`, `au3_cosmos`, `au3_<режим>_r`). Старые
   форматы (v1, v2) мигрируют в «Космос» — не ломай `applySave`.
5. Никогда не проси токен бота в чате и не вставляй личные данные владельца в код и запросы.

## Стиль
- Иконки: «неоновый космос» как у аватарки бота — градиенты, светлая обводка, искорки (`spark`).
  **Не должно быть похоже на эмодзи.** В шаблонах `__` заменяется на уникальный префикс id градиентов.
  Хелперы: `spark, radG, linG, shine, ball, halo, arcHalf, burst, rays`. Кольца/орбиты должны
  проходить ЗА сферой (`arcHalf`). Горизонтальные линии — без градиента (не отрисуется).
- Звуки: низкие и мягкие, «модерн». Успех — короткий «блуп» вверх, неудача — две мягкие ноты вниз.
  Один общий звук для всех кнопок, кроме «Очистки» и «Корзины».
- Интерфейс должен помещаться на телефоне 375×812, без переносов в шапке.

## Проверка
Локальный сервер: `python -m http.server 8765`, открыть `http://localhost:8765/`, ширина 375×812.
Вне Telegram игра работает (CloudStorage и вибрация просто отключаются).

## Как публиковать
Изменения попадают к игрокам только после попадания в `main` на GitHub. В облачной сессии работай
в своей ветке; в `main` вливай, когда владелец одобрил. Коротко сообщай, что изменилось, и
напоминай: если в боте старая версия — закрыть игру и открыть заново.
